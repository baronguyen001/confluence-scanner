# Comparison

| Project | Use it when | Use `confluence-scanner` when |
| --- | --- | --- |
| Freqtrade | You need a full bot with exchange execution. | You want a research and alert framework before wiring execution. |
| Backtrader | You need a mature general backtesting engine. | You want a small crypto-oriented package with public data fetchers. |
| vectorbt | You need large vectorized parameter sweeps. | You want a CLI, examples, multi-channel alerts, and walk-forward helpers in one repo. |

This repo is deliberately narrow: signals, scoring, validation, alerts, and scheduler snippets.
